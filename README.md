# 老九黑板

> 一款专业的交互式电子白板与数学几何绘图工具，适用于教学演示、数学绘图和文档批注。

![版本](https://img.shields.io/badge/版本-1.76.8-blue)
![许可证](https://img.shields.io/badge/许可证-Apache%202.0-green)

---

## 功能一览

| 类别 | 功能 |
|------|------|
| **绘图工具** | 手绘、直线、矩形、椭圆、多边形、自由曲线 |
| **几何构造** | 点、线、圆、交点、中点、垂线、平行线、角平分线 |
| **圆锥曲线** | 椭圆、双曲线、抛物线（参数方程） |
| **函数绘图** | 显函数、隐函数、参数方程、幂函数、切线 |
| **坐标系** | 建立/管理坐标系，支持多个坐标系 |
| **变换操作** | 旋转、对称（镜像）、缩放、平移 |
| **标记测量** | 距离、角度、面积测量 |
| **标签注释** | 文本标签、Markdown 笔记 |
| **文件处理** | PDF 导入批注、图片导入、.ban 专用格式 |
| **云端同步** | 百度网盘集成，多设备同步 |
| **视频处理** | 内置视频处理能力 |
| **视图控制** | 缩放、平移、全屏、页面管理 |

## 核心概念：「画」与「构造」

| | **画（Draw）** | **构造（Construct）** |
|---|---|---|
| **起点** | 从空白开始 | 从已有对象开始 |
| **特点** | 直观、适合草图 | 精确、保持几何约束关系 |
| **例子** | 画直线：点击直线图标 → 点起点 → 拖到终点 | 构造线段：选中两个点 → 点击"构造线段" |

同一个图形通常有多种创建方式。例如创建圆：可手动画圆、圆心+点构造、三点定圆、或圆锥曲线参数创建。
