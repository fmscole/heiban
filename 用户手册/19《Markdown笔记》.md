## Markdown 笔记 [编辑]

### 作用
在画布上插入 Markdown 格式的富文本笔记，支持公式、图片、代码块等。

### 操作步骤
1. 在右侧菜单点击 **视图 → 新建笔记**（或使用快捷键）
2. 在弹出对话框中输入 Markdown 内容，例如：

```markdown
# 标题
- 列表项1
- 列表项2

公式：$E = mc^2$

代码：
`python
print("hello")
`
```

3. 点击确定
4. 笔记显示在画布上，可拖动调整位置

### 支持的 Markdown 语法
| 语法 | 效果 |
|------|------|
| `# 标题` | 一级标题 |
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `- 列表` | 无序列表 |
| `$E=mc^2$` | 行内公式（KaTeX渲染） |
| `$$x^2$$` | 独立公式块 |
| `[链接](url)` | 超链接 |
| `` `代码` `` | 代码块 |

## 笔记操作

### 编辑笔记
1. 双击画布上的笔记
2. 在编辑器中修改内容
3. 点击空白处完成编辑

### 移动笔记
切换到选择模式，拖动笔记到目标位置。

### 调整字体大小
在右侧菜单中调整笔记的字体大小。

### 笔记渲染为图片
大段笔记可渲染为图片，提高画布性能：
1. 选中笔记
2. 右键选择 **渲染为图片**
3. 笔记转为不可编辑的图片格式

## 笔记锚点

### 作用
将笔记锚定到某个几何点上，笔记会随该点移动。

### 操作步骤
1. 选中一个点
2. 创建笔记时，笔记会自动锚定到该点
3. 或：先创建笔记，再拖动笔记将其关联到某个点
