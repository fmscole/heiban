本章介绍基于已有点/线/圆**构造**新点的操作。构造出的点具有**动态关联性**：当原始对象移动时，构造点自动更新位置。

> **前提**：所有构造操作都需要先有可依赖的已有对象（点、线、圆等）。如果没有，请先用第05章的"点工具"或"直线工具"画出基础对象。

## 构造交点 [构造]

### 作用
自动计算并创建两个几何对象的交点。是最常用的构造操作之一。

### 操作步骤
1. 确保画布上有两条相交的线（或线与圆、圆与圆等）
2. 点击左侧菜单 **更多 → 构造交点**
3. 系统自动扫描所有选中或可见对象，创建所有可能的交点：
   - 直线与直线交点
   - 直线与圆交点（2个）
   - 圆与圆交点（2个）
   - 直线与椭圆/双曲线/抛物线交点
   - 圆与椭圆/双曲线/抛物线交点
4. 交点被创建后，拖动原始对象时交点联动更新

> **批量操作**：此功能会一次性创建所有可计算交点。如果只想创建特定两条线的交点，可用下面的"手动选择交点"方式。

## 直线交点（手动选择）[构造]

### 作用
手动指定两条直线，创建它们的交点。

### 操作步骤
1. 选中第一条直线（点击它）
2. 按住 Shift，选中第二条直线
3. 在右侧菜单点击 **构造 → 直线交点**
4. 交点创建在两线相交处

> 如果两线平行（无交点），不会创建任何点。

## 直线与圆交点 [构造]

### 作用
求直线与圆的交点，可能产生 0 个、1 个（相切）或 2 个交点。

### 操作步骤
1. 选中一条直线
2. 按住 Shift，选中一个圆
3. 在右侧菜单点击 **构造 → 直线与圆交点**
4. 系统自动创建所有交点（最多2个）

## 两圆交点 [构造]

### 作用
求两个圆的交点。

### 操作步骤
1. 选中第一个圆
2. 按住 Shift，选中第二个圆
3. 在右侧菜单点击 **构造 → 两圆交点**
4. 交点自动创建（0-2个）

## 中点 [构造]

### 作用
创建线段的中点，始终位于两端点正中间。

### 操作步骤
1. 选中两个点（点击第一个，按住 Shift 点击第二个）
2. 在右侧菜单点击 **构造 → 中点**
3. 中点创建，拖动任意端点时中点保持居中

> 也可以选中一条线段（直线/射线/构造线段），直接构造其中点。

## 坐标点 [构造]

### 作用
通过精确的数学坐标值创建点。

### 前置条件
- 必须先建立坐标系（见第02章）

### 操作步骤
1. 确保已有坐标系
2. 在右侧菜单点击 **构造 → 坐标点**
3. 在对话框中输入：
   - **x坐标**：支持数学表达式（如 `2*pi`、`sqrt(2)`、`a+b`）
   - **y坐标**：同上
4. 点击确定，点创建在指定坐标位置

**示例**：
- `(3, 4)` → 输入 x=3, y=4
- `(sin(30°), cos(30°))` → 输入 x=sin(pi/6), y=cos(pi/6)

## 线上点 [构造]

### 作用
在已有直线上创建一个可沿该线滑动的约束点。

### 操作步骤
1. 点击左侧菜单 **点图标** 进入点模式
2. 将鼠标移到某条直线上（自动吸附高亮）
3. 点击放置点 → 创建"线上点"
4. 切换到选择模式后，可沿该线拖动此点

> **已有线上创建**：也可以选中一条线，在右侧菜单点击 **构造 → 线上点**，然后在线上点击确定位置。

## 圆上点 [构造]

### 作用
在已有圆周上创建一个可沿圆周滑动的约束点。

### 操作步骤
1. 点击左侧菜单 **点图标** 进入点模式
2. 将鼠标移到某个圆上（自动吸附高亮）
3. 点击放置点 → 创建"圆上点"
4. 拖动此点时，始终保持在圆周上

## 曲线上点 [构造]

### 作用
在函数曲线或圆锥曲线上创建约束点。

### 操作步骤
1. 点击 **点图标**
2. 将鼠标移到曲线上（自动吸附）
3. 点击创建约束点
4. 点可沿曲线滑动
