## 任意函数 [参数]

### 作用
绘制自定义显函数曲线 y=f(x)。最灵活的函数绘图工具。

### 操作步骤
1. 点击左侧菜单 **更多 → 任意函数**
2. 在"函数解析式"对话框中输入表达式：

| 表达式 | 曲线 |
|--------|------|
| `sin(x)` | 正弦曲线 |
| `cos(x)` | 余弦曲线 |
| `tan(x)` | 正切曲线 |
| `x^2` | 抛物线 |
| `x^3` | 三次曲线 |
| `log(x)` | 对数曲线 |
| `exp(x)` | 指数曲线 |
| `sqrt(x)` | 平方根曲线 |
| `abs(x)` | 绝对值曲线 |

3. 设置 x 的范围：
   - **xmin**：左边界（如 -10）
   - **xmax**：右边界（如 10）
4. 设置 y 轴显示范围（可选）：
   - **ymin**、**ymax**
5. 点击 **确定** 绘制

### 支持的高级表达式
- 组合函数：`sin(x) + cos(x)`
- 嵌套函数：`sin(x^2)`
- 参数引用：如已设置参数 a，可用 `a*sin(x)`

## 二次函数 [参数]

### 作用
绘制抛物线 y = ax² + bx + c。

### 操作步骤
1. 点击左侧菜单 **更多 → 二次函数**
2. 在弹出的对话框中输入：
   - **a**：二次项系数
   - **b**：一次项系数（点击第二步确定）
   - **c**：常数项（点击第三步确定）
3. 设置 x 范围
4. 点击确定绘制

> 也可通过鼠标操作：点击三个点来确定经过这三点的抛物线。

## 幂函数 [参数]

### 作用
绘制 y = x^(m/n) 形式的幂函数。

### 操作步骤
1. 点击左侧菜单 **更多 → 代数图形 → 幂函数**
2. 设置幂指数：
   - **m**（分子）：如 1
   - **n**（分母）：如 2
3. m=1, n=2 → y = x^(1/2) = √x（平方根函数）
4. m=3, n=1 → y = x³（三次函数）

> **n 必须为正整数**。负指数通过 m 取负值实现。

## 常用函数表达式速查

| 函数 | 表达式 | 定义域注意 |
|------|--------|------------|
| 正弦 | `sin(x)` | 全实数 |
| 余弦 | `cos(x)` | 全实数 |
| 正切 | `tan(x)` | x ≠ π/2 + kπ |
| 自然对数 | `log(x)` | x > 0 |
| 常用对数 | `log(x)/log(10)` | x > 0 |
| 指数(e) | `exp(x)` | 全实数 |
| 平方根 | `sqrt(x)` | x ≥ 0 |
| 绝对值 | `abs(x)` | 全实数 |
| 取整 | `floor(x)` | 全实数 |

> 完整支持函数列表见 math.js 文档。黑板底层使用 math.js 引擎计算表达式。
