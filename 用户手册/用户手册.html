功能介绍

老九黑板 - 功能介绍

应用概述

老九黑板是一款专业的交互式电子白板与数学几何绘图工具，适用于教学演示、数学绘图和文档批注。

界面布局

┌──────────┬──────────────┬──────────┐
│ 左侧菜单 │   画布区域   │ 右侧菜单 │
│  50px宽  │   主工作区   │  可折叠  │
└──────────┴──────────────┴──────────┘
  • 左侧菜单（竖排图标）：包含画笔、直线、矩形、选择、擦除等常用工具，以及"更多"子菜单（圆、坐标系、函数、圆锥曲线等）
  • 右侧菜单（可折叠）：包含构造、变换、标记、测量等功能，通过右键菜单或右侧面板使用
  • 画布区域：主工作区，所有图形在此创建和编辑

核心概念：「画」与「构造」

理解这两个概念是掌握黑板的关键：

画（Draw） 构造（Construct）
起点 从空白开始 从已有对象开始
操作方式 点击菜单→在画布上鼠标操作逐步成型 选中已有对象→点击菜单→生成新对象
例子 画直线：点击直线图标→点起点→拖到终点 构造线段：选中两个点→点击"构造线段"
特点 直观、适合草图 精确、保持几何约束关系

同一个图形通常有多种创建方式。例如创建圆：

  • 画圆：左侧菜单 → 更多 → 画圆 → 点击圆心 → 拖动确定半径
  • 圆心+点构圆：先画两个点 → 选中它们 → 右侧菜单 → 构造 → 圆心+点构圆
  • 三点定圆：先画三个点 → 选中它们 → 右侧菜单 → 构造 → 三点构圆
  • 圆锥曲线圆：左侧菜单 → 更多 → 代数图形 → 圆锥曲线圆 → 输入参数创建

本手册在每个功能的标题旁标注 [画] 或 [构造]，帮助你快速识别。

建立坐标系

建立坐标系

为什么需要坐标系

坐标系是精确绘图的基准，以下功能依赖坐标系：

功能类型 具体功能
函数绘图 任意函数、二次函数、幂函数
精确绘图 坐标点、圆锥曲线椭圆/双曲线/抛物线/圆
隐函数曲线 f(x,y)=0 形式的任意隐函数
测量计算 坐标距离、角度计算、三角形面积
数值分析 参数方程、数值积分

没有坐标系时，画布使用像素坐标；建立坐标系后，使用数学坐标。

建立坐标系（"一拖三点击"） [画]

步骤1：拖动画出范围

  1. 点击左侧菜单 更多 → 坐标系 → 建立坐标系
  2. 在画布上拖动鼠标画出一个矩形区域——这确定了坐标系的 x 轴和 y 轴的可见范围

步骤2：点击确定原点

点击画布确定坐标原点 O 的位置。

步骤3：点击确定X轴单位点

在原点右侧（X轴正方向）点击，确定：

  • X 轴正方向
  • X 轴单位长度（原点到此点的距离 = 1 个单位）

步骤4：点击确定Y轴单位点

在原点上方（Y轴正方向）点击，确定：

  • Y 轴正方向
  • Y 轴单位长度

完成后

坐标轴显示在画布上，包含：

  • X 轴（红色箭头，向右为正）
  • Y 轴（蓝色/绿色箭头，向上为正）
  • 原点 O
  • 单位刻度标记

调整坐标系

显示/隐藏控制点

  • 显示：左侧菜单 更多 → 坐标系 → 显示坐标控制点 —— 显示所有调节手柄
  • 隐藏：左侧菜单 更多 → 坐标系 → 隐藏坐标控制点 —— 隐藏手柄防止误操作

拖动单位点改变比例

  1. 显示控制点后，可看到 X 轴和 Y 轴上的单位点
  2. 拖动单位点改变单位长度
  3. 基于该坐标系的所有图形同步缩放

移动坐标系

  • 在原点附近点击选中整个坐标系
  • 拖动原点可整体移动坐标系
  • 所有基于坐标的图形跟随移动

修改坐标范围

  • 拖动 X 轴或 Y 轴的端点可以改变轴的显示范围

多坐标系管理

每个页面支持多个坐标系

  • 同一页面可建立多个独立坐标系
  • 每个坐标系有自己的原点和单位长度
  • 不同坐标系的图形互不干扰

切换活动坐标系

点击对应坐标系的原点（或轴上任意位置），该坐标系变为当前活动坐标系。后续创建的坐标相关图形都基于此坐标系。

删除坐标系

  1. 选中坐标系（点击原点）
  2. 按 Delete 键
  3. 基于该坐标系的所有图形也一并删除

⚠️ 删除坐标系会同时删除所有依赖它的图形（函数曲线、坐标点等）。

文件管理

文件管理

新建黑板

操作步骤

  1. 点击左侧菜单 文件夹图标 → 黑板
  2. 新建一个空白黑板文件
  3. 默认名称"heiban"，包含一个空白页

打开本地文件

操作步骤

  1. 点击左侧菜单 文件夹图标 → 打开本地文件
  2. 在系统文件对话框中选择文件
  3. 支持格式：.ban（黑板专用）、.pdf、图片文件

打开百度网盘文件

前置条件

  • 需要先登录百度网盘账号

操作步骤

  1. 点击左侧菜单 文件夹图标 → 打开百度网盘文件
  2. 在弹出的网盘文件浏览器中选择文件
  3. 点击打开

保存文件

保存为 ban 文件

  1. 点击左侧菜单 文件夹图标 → 保存ban文件
  2. 如果是新文件，弹出保存对话框
  3. 如果是已打开的文件，直接覆盖保存
  4. .ban 格式保留所有可编辑信息（点、线、构造关系等）

另存为 ban 文件

  1. 点击 文件夹图标 → 另存为ban文件
  2. 选择保存位置和文件名
  3. 原文件不受影响

保存为 PDF

  1. 点击 文件夹图标 → 保存为PDF
  2. 所有页面导出为一个 PDF 文件
  3. 每页画布对应一页 PDF

当前页保存为图片

  1. 点击 文件夹图标 → 当前页保存为图片
  2. 当前页导出为 PNG 图片
  3. 可用于分享或插入其他文档

批量导入文件

批量导入文件

批量导入PDF页面

作用

将多页 PDF 文件的每一页分别导入到黑板的连续页面中。

操作步骤

  1. 点击左侧菜单 文件夹图标 → 打开本地文件
  2. 选择一个 PDF 文件
  3. PDF 的每一页按顺序导入：
    • 第1页 PDF → 黑板第1页
    • 第2页 PDF → 黑板第2页
    • ...以此类推

导入后的操作

  • 每页 PDF 作为背景图片显示
  • 可以在 PDF 上方自由绘制批注
  • 切换页面时，批注跟随各自页面
  • 保存为 .ban 文件时，PDF 背景和批注一起保存

批量导入图片

操作步骤

  1. 点击左侧菜单 文件夹图标 → 打开本地文件
  2. 选择多个图片文件（Ctrl+点击多选）
  3. 每个图片导入到独立的一页

导入注意事项

PDF 导入

  • 大尺寸 PDF 导入可能需要较长时间
  • PDF 分辨率由黑板页面大小决定
  • 导入后可切换"原图/二极化"模式

文件关联

  • 导入的 PDF/图片作为背景层，不可移动或删除（需通过删除页面来移除）
  • 绘图内容在前景层，可自由编辑

支持的格式

格式 导入方式 每页对应
.ban 直接打开编辑 保留多页结构
PDF 导入为背景 每页PDF → 每页黑板
PNG/JPG 导入为背景 每个图片 → 每页黑板
WebP/BMP/GIF 导入为背景 每个图片 → 每页黑板

绘图工具-上

绘图工具（上）——「画」模式

本章介绍左侧菜单中的「画」模式工具。这些工具的共性是：从空白画布开始，通过鼠标点击、拖动逐步成型，不依赖已有对象。

与「构造」的区别：如果想基于已有点/线创建新图形（如过两点构造线段、过三点构造圆），请参阅第07-10章"几何构造"。

画笔工具 [画]

作用

自由手绘曲线，用于手写文字、涂鸦标记、随意绘图。

操作步骤

  1. 点击左侧菜单 铅笔图标（或展开后选择具体笔型）
  2. 在画布上按住鼠标左键拖动绘制
  3. 松开鼠标完成一笔

笔型选择

点击铅笔图标展开子菜单，可选：

  • 树枝笔：模拟树枝/粉笔质感
  • 圆珠笔：标准圆头笔迹
  • 水笔：流畅线条
  • 空心笔：空心轮廓线
  • 画笔：艺术画笔效果
  • 马克笔：半透明宽笔触（自动切换为马克笔颜色）

调整笔迹

  • 在 线条样式 菜单中调整笔画粗细（1-20号）
  • 通过颜色选择器改变画笔颜色

直线工具 [画]

作用

绘制精确的直线段。

操作步骤

  1. 点击左侧菜单 直线图标
  2. 在画布上点击确定起点
  3. 拖动鼠标到终点位置
  4. 再次点击（或释放鼠标）确定终点

自动吸附

绘制时起点和终点会自动吸附到附近的：

  • 已有点（8px范围内）
  • 已有线上的最近点
  • 已有圆/椭圆/曲线上的最近点

变为向量

选中直线后，点击 更多 → 变为向量，直线两端会加上箭头。

构造线段：如果先有两个点，想精确连接它们，应使用「构造线段」（见第09章），这样线段会跟随点移动。

矩形工具 [画]

作用

绘制矩形框，用于框选区域、创建边框。

操作步骤

  1. 点击左侧菜单 矩形图标
  2. 在画布上点击确定矩形的一个角
  3. 拖动鼠标到对角位置
  4. 再次点击确定矩形

点工具 [画]

作用

在画布上放置自由点，是构造其他图形的基础。

操作步骤

  1. 点击左侧菜单 点图标
  2. 在画布上点击放置点
  3. 每点一次放置一个点
  4. 切换到选择模式后可拖动点

自动吸附

放置点时自动吸附到：

  • 已有线上的最近点 → 创建"线上点"（可沿该线滑动）
  • 已有圆上的最近点 → 创建"圆上点"（可沿圆周滑动）
  • 已有曲线上的最近点 → 创建"曲线上点"
  • 无吸附对象时 → 创建"自由点"

吸附创建的点具有约束关系，拖动时始终保持在吸附对象上。这是「构造」概念的体现。

虚线工具 [画]

作用

绘制虚线，常用于辅助线、隐藏边、对称轴。

操作步骤

  1. 点击左侧菜单 更多 → 画虚线
  2. 点击确定虚线起点
  3. 拖动到终点位置释放

画圆 [画]

作用

通过圆心+半径的方式画圆。

操作步骤

  1. 点击左侧菜单 更多 → 画圆
  2. 在画布上点击确定圆心位置
  3. 拖动鼠标确定半径大小
  4. 再次点击完成

圆的多种创建方式：除了"画圆"，还可以通过「圆心+点构圆」「三点定圆」「圆锥曲线圆」等方式创建（见第10章）。不同方式的区别在于是否保持几何约束。

绘图工具-下

绘图工具（下）—— 编辑与擦除

本章介绍编辑和擦除类工具。

选择工具

作用

选择画布上的对象，是进行移动、删除、变换等操作的前提。

操作步骤

  1. 点击左侧菜单 光标图标 进入选择模式
  2. 单选：点击画布上的任意图形（点/线/圆/曲线）
  3. 多选：按住 Shift 依次点击多个对象
  4. 框选：在空白处按住鼠标拖动，框内所有对象被选中
  5. 选中的对象高亮显示（红色边框）
  6. 在空白处点击取消所有选中

选中后可执行的操作

  • 拖动：切换到移动模式（箭头图标），拖动选中对象
  • 删除：按 Delete 键或 Backspace 键
  • 变换：使用右侧菜单的"运动"功能（旋转/对称/缩放/平移）
  • 构造：使用右侧菜单的"构造"功能（中点/交点等）
  • 隐藏：右键 → 隐藏选中对象
  • 置顶/置底：右键调整图层顺序

移动工具

作用

拖动画布或移动图形。

操作步骤

  1. 点击左侧菜单 移动图标（十字箭头）
  2. 在画布上按住拖动：
    • 拖动空白区域 → 平移整个画布视图
    • 拖动选中的图形 → 移动图形位置
  3. 也可使用鼠标中键/右键拖动来平移视图

线条样式

作用

调整新绘制图形的线条粗细。不影响已选中图形的粗细。

操作步骤

  1. 点击左侧菜单 线条样式图标
  2. 选择粗细等级：1号（最细）到 20号（最粗）
  3. 后续新绘制的图形使用此粗细

修改已有图形的粗细

  1. 选中要修改的图形
  2. 在线条样式菜单中选择新粗细
  3. 选中图形立即更新

擦除工具

橡皮擦除 [编辑]

擦除已绘制的手写笔迹和曲线。

操作步骤：

  1. 点击左侧菜单 橡皮图标（或展开选择擦除模式）
  2. 按住鼠标在要擦除的区域拖动
  3. 经过的笔迹被擦除（粗线覆盖式擦除）

选择擦除 [编辑]

点击单个对象来擦除它。

操作步骤：

  1. 展开橡皮图标子菜单 → 选择擦除
  2. 点击画布上的图形
  3. 被点击的图形立即删除

矩形擦除 [编辑]

框选一个矩形区域，擦除区域内所有图形。

操作步骤：

  1. 展开橡皮图标子菜单 → 矩形擦除
  2. 在画布上拖动创建矩形区域
  3. 释放鼠标，区域内所有图形被删除

矩形覆盖 [编辑]

作用

用填充矩形覆盖画布区域，用于遮盖或高亮。

操作步骤：

  1. 展开橡皮图标子菜单 → 矩形覆盖
  2. 在画布上拖动创建填充矩形
  3. 矩形使用当前背景色填充，遮盖下方内容
  4. 可用于制作"逐步揭示"的教学效果

擦除覆盖与橡皮 [编辑]

作用

一次性清除所有矩形覆盖和橡皮擦除产生的粗线。

操作步骤：

  1. 展开橡皮图标子菜单 → 擦除覆盖与橡皮
  2. 画布上所有覆盖矩形和橡皮擦除痕迹被清除
  3. 被擦除的原始笔迹不会恢复

撤销恢复：如果误擦了内容，可以使用右侧菜单中的"撤销"按钮（或 Ctrl+Z）恢复。

几何图形工具 [画]

几何构造-点

几何构造——点

本章介绍基于已有点/线/圆构造新点的操作。构造出的点具有动态关联性：当原始对象移动时，构造点自动更新位置。

前提：所有构造操作都需要先有可依赖的已有对象（点、线、圆等）。如果没有，请先用第05章的"点工具"或"直线工具"画出基础对象。

构造交点 [构造]

作用

自动计算并创建两个几何对象的交点。是最常用的构造操作之一。

操作步骤

  1. 确保画布上有两条相交的线（或线与圆、圆与圆等）
  2. 点击左侧菜单 更多 → 构造交点
  3. 系统自动扫描所有选中或可见对象，创建所有可能的交点：
    • 直线与直线交点
    • 直线与圆交点（2个）
    • 圆与圆交点（2个）
    • 直线与椭圆/双曲线/抛物线交点
    • 圆与椭圆/双曲线/抛物线交点
  4. 交点被创建后，拖动原始对象时交点联动更新

批量操作：此功能会一次性创建所有可计算交点。如果只想创建特定两条线的交点，可用下面的"手动选择交点"方式。

直线交点（手动选择）[构造]

作用

手动指定两条直线，创建它们的交点。

操作步骤

  1. 选中第一条直线（点击它）
  2. 按住 Shift，选中第二条直线
  3. 在右侧菜单点击 构造 → 直线交点
  4. 交点创建在两线相交处

如果两线平行（无交点），不会创建任何点。

直线与圆交点 [构造]

作用

求直线与圆的交点，可能产生 0 个、1 个（相切）或 2 个交点。

操作步骤

  1. 选中一条直线
  2. 按住 Shift，选中一个圆
  3. 在右侧菜单点击 构造 → 直线与圆交点
  4. 系统自动创建所有交点（最多2个）

两圆交点 [构造]

作用

求两个圆的交点。

操作步骤

  1. 选中第一个圆
  2. 按住 Shift，选中第二个圆
  3. 在右侧菜单点击 构造 → 两圆交点
  4. 交点自动创建（0-2个）

中点 [构造]

作用

创建线段的中点，始终位于两端点正中间。

操作步骤

  1. 选中两个点（点击第一个，按住 Shift 点击第二个）
  2. 在右侧菜单点击 构造 → 中点
  3. 中点创建，拖动任意端点时中点保持居中

也可以选中一条线段（直线/射线/构造线段），直接构造其中点。

坐标点 [构造]

作用

通过精确的数学坐标值创建点。

前置条件

  • 必须先建立坐标系（见第02章）

操作步骤

  1. 确保已有坐标系
  2. 在右侧菜单点击 构造 → 坐标点
  3. 在对话框中输入：
    • x坐标：支持数学表达式（如 2*pi、sqrt(2)、a+b）
    • y坐标：同上
  4. 点击确定，点创建在指定坐标位置

示例：

  • (3, 4) → 输入 x=3, y=4
  • (sin(30°), cos(30°)) → 输入 x=sin(pi/6), y=cos(pi/6)

线上点 [构造]

作用

在已有直线上创建一个可沿该线滑动的约束点。

操作步骤

  1. 点击左侧菜单 点图标 进入点模式
  2. 将鼠标移到某条直线上（自动吸附高亮）
  3. 点击放置点 → 创建"线上点"
  4. 切换到选择模式后，可沿该线拖动此点

已有线上创建：也可以选中一条线，在右侧菜单点击 构造 → 线上点，然后在线上点击确定位置。

圆上点 [构造]

作用

在已有圆周上创建一个可沿圆周滑动的约束点。

操作步骤

  1. 点击左侧菜单 点图标 进入点模式
  2. 将鼠标移到某个圆上（自动吸附高亮）
  3. 点击放置点 → 创建"圆上点"
  4. 拖动此点时，始终保持在圆周上

曲线上点 [构造]

作用

在函数曲线或圆锥曲线上创建约束点。

操作步骤

  1. 点击 点图标
  2. 将鼠标移到曲线上（自动吸附）
  3. 点击创建约束点
  4. 点可沿曲线滑动

几何构造-线

几何构造——线

本章介绍基于已有点/线构造新线的操作。所有构造出的线具有动态关联性。

「画」vs「构造」：左侧菜单的"直线工具"是画线段（自由放置）；本章的"构造线段/射线/直线"基于已有点创建，会随点移动。

构造线段 [构造]

作用

连接两个已有点创建线段。拖动端点时线段跟随变化。

操作步骤

  1. 确保画布上有两个点
  2. 选中这两个点（点击第一个，Shift+点击第二个）
  3. 在右侧菜单点击 构造 → 构造线段
  4. 线段自动连接两点

与「画直线」的区别：

  • 画直线：从空白开始，自由放置起点和终点
  • 构造线段：基于已有点，保持关联约束

构造射线 [构造]

作用

从一个点出发，经过另一点，向一个方向无限延伸的射线。

操作步骤

  1. 选中起点
  2. 按住 Shift，选中方向点
  3. 在右侧菜单点击 构造 → 构造射线
  4. 射线从起点向方向点延伸

构造直线 [构造]

作用

通过两点创建向两端无限延伸的直线。

操作步骤

  1. 选中两个点
  2. 在右侧菜单点击 构造 → 构造直线
  3. 直线通过两点，两端无限延伸

构造直线与左侧菜单的"直线工具"（画线段）不同。构造直线会显示为穿过两点的无限直线。

平行线 [构造]

作用

过一点作某直线的平行线。

操作步骤

  1. 选中一条参考直线（作为平行基准）
  2. 按住 Shift，选中要通过的点
  3. 在右侧菜单点击 构造 → 平行线
  4. 过该点且与参考线平行的直线被创建

垂线 [构造]

作用

过一点作某直线的垂线。

操作步骤

  1. 选中一条参考直线
  2. 按住 Shift，选中垂足位置的点（或要通过的点）
  3. 在右侧菜单点击 构造 → 垂线
  4. 垂线自动创建（过该点且垂直于参考线）

角平分线 [构造]

作用

作一个角的平分线。

操作步骤

  1. 选中三个点（按顺序：角的一边上一点 → 顶点 → 另一边上的点）
  2. 在右侧菜单点击 构造 → 角平分线
  3. 角平分线从顶点出发，平分该角

示例：有 A、O、B 三点，要作∠AOB的平分线：

  • 选中 A → Shift+选中 O → Shift+选中 B
  • 点击 构造 → 角平分线

几何构造-圆

几何构造——圆

本章介绍圆的多种创建方式。同一个圆可以通过「画」或「构造」不同的方式得到，选择哪种取决于你的需求。

圆的四种创建方式

创建圆有四种基本方式，各有不同的适用场景：

方式 菜单位置 模式 约束关系
画圆 左侧菜单 更多→画圆 画 无约束，自由放置
圆心+点构圆 右侧菜单 构造 构造 圆心和半径跟随两点变化
三点定圆 右侧菜单 构造 构造 圆始终经过三点
圆锥曲线圆 左侧菜单 更多→代数图形 参数 通过参数方程精确定义

画圆 [画]

作用

用圆心+半径的方式画圆。

操作步骤

  1. 点击左侧菜单 更多 → 画圆
  2. 在画布上点击确定圆心
  3. 拖动鼠标确定半径大小
  4. 再次点击完成

画出的圆是自由图形，不与任何点关联。适合快速绘制。

圆心+点构圆 [构造]

作用

以第一个点为圆心，经过第二个点的圆。两点移动时圆跟随变化。

操作步骤

  1. 画两个点（用点工具）
  2. 选中第一个点（圆心）
  3. 按住 Shift，选中第二个点（圆周上的点）
  4. 在右侧菜单点击 构造 → 圆心+点构圆
  5. 圆创建，圆心在第一个点，圆周经过第二个点

拖动两个点中的任意一个，圆都会实时更新。

三点定圆 [构造]

作用

通过不在同一直线上的三点确定唯一圆。

操作步骤

  1. 画三个不共线的点
  2. 依次选中三个点（Shift+点击）
  3. 在右侧菜单点击 构造 → 三点构圆
  4. 经过三点的圆自动创建

圆心+距离构圆 [构造]

作用

以指定点为圆心，用数值或表达式指定半径的圆。

操作步骤

  1. 选中圆心点
  2. 在右侧菜单点击 构造 → 圆心+距离构圆
  3. 输入半径值（支持表达式）
  4. 圆按指定半径创建

圆锥曲线-椭圆

椭圆有两种创建方式：画椭圆（几何方式，鼠标放置控制点）和圆锥曲线椭圆（代数方式，输入参数方程）。两种方式产生的椭圆性质不同。

画椭圆 [画]

作用

通过鼠标放置控制点来画椭圆。适合快速、直观的绘制。

操作步骤

  1. 点击左侧菜单 更多 → 几何图形 → 画椭圆
  2. 在画布上点击第一个点（椭圆中心或长轴一端）
  3. 点击第二个点（确定长轴方向和长度）
  4. 拖动鼠标调整短轴长度
  5. 点击确认，椭圆完成

画出的椭圆是自由图形，不与坐标系关联。

圆锥曲线椭圆 [参数]

作用

通过精确的数学参数创建标准椭圆，需要坐标系。

前置条件

  • 必须先建立坐标系（见第02章）

操作步骤

  1. 点击左侧菜单 更多 → 代数图形 → 圆锥曲线椭圆
  2. 在弹出的参数面板中设置：
参数 说明 示例值
a 半长轴长度 4
b 半短轴长度 2
中心点 x 椭圆中心x坐标 0
中心点 y 椭圆中心y坐标 0
旋转角 椭圆倾斜角度（度） 30
  1. 点击 创建 按钮
  2. 椭圆按参数生成，从属于当前坐标系

参数化椭圆的优势

  • 精确的数学定义
  • 可设置旋转角度
  • 可拖动中心点改变位置
  • 坐标变化时椭圆跟随缩放

椭圆上的点 [构造]

作用

在椭圆周上创建可滑动的约束点。

使用技巧

等号表达式

输入 y = x^2 会自动转换为 y - x^2，等价于 y - x^2 = 0。

计算精度

复杂曲线或表达式变化剧烈的区域可能需要更密集的网格计算。如果曲线有断点或缺失：

  • 尝试调整坐标系的显示范围
  • 缩小 xmin/xmax/ymin/ymax 范围提高精度

与显函数的区别

  • 显函数 y=f(x)：通过「任意函数」工具绘制，速度快，但每个 x 只能对应一个 y
  • 隐函数 f(x,y)=0：通过本工具绘制，能表达闭合曲线和多值函数，但计算较慢

变换操作

变换操作属于 [构造] 模式——需先选中对象，再通过右侧菜单执行。变换结果保留原始对象，与原对象保持动态关联（修改原对象或变换参数时结果自动更新）。可对结果再次变换（链式变换），删除变换结果选中后按 Delete 键。

通用前提：所有变换操作都需要先选中至少一个对象。

  3. 依次点击平移向量的起点和终点
  4. 图形按向量方向和距离平移（修改向量起终点会联动更新）

函数绘图绘制显函数 y=f(x) 曲线，属于 [参数] 模式——通过输入数学表达式创建，需要坐标系。

前置条件：以下所有函数绘图操作都需要先建立坐标系（见第02章）。

任意函数 [参数]

作用

绘制自定义显函数曲线 y=f(x)。最灵活的函数绘图工具。

操作步骤

  1. 点击左侧菜单 更多 → 任意函数
  2. 在"函数解析式"对话框中输入表达式：
表达式 曲线
sin(x) 正弦曲线
cos(x) 余弦曲线
tan(x) 正切曲线
x^2 抛物线
x^3 三次曲线
log(x) 对数曲线
exp(x) 指数曲线
sqrt(x) 平方根曲线
abs(x) 绝对值曲线
  1. 设置 x 的范围：
    • xmin：左边界（如 -10）
    • xmax：右边界（如 10）
  2. 设置 y 轴显示范围（可选）：
    • ymin、ymax
  3. 点击 确定 绘制

支持的高级表达式

  • 组合函数：sin(x) + cos(x)
  • 嵌套函数：sin(x^2)
  • 参数引用：如已设置参数 a，可用 a*sin(x)

二次函数 [参数]

作用

绘制抛物线 y = ax² + bx + c。

操作步骤

  1. 点击左侧菜单 更多 → 二次函数
  2. 在弹出的对话框中输入：
    • a：二次项系数
    • b：一次项系数（点击第二步确定）
    • c：常数项（点击第三步确定）
  3. 设置 x 范围
  4. 点击确定绘制

也可通过鼠标操作：点击三个点来确定经过这三点的抛物线。

幂函数 [参数]

作用

绘制 y = x^(m/n) 形式的幂函数。

操作步骤

  1. 点击左侧菜单 更多 → 代数图形 → 幂函数
  2. 设置幂指数：
    • m（分子）：如 1
    • n（分母）：如 2
  3. m=1, n=2 → y = x^(1/2) = √x（平方根函数）
  4. m=3, n=1 → y = x³（三次函数）

n 必须为正整数。负指数通过 m 取负值实现。

常用函数表达式速查

函数 表达式 定义域注意
正弦 sin(x) 全实数
余弦 cos(x) 全实数
正切 tan(x) x ≠ π/2 + kπ
自然对数 log(x) x > 0
常用对数 log(x)/log(10) x > 0
指数(e) exp(x) 全实数
平方根 sqrt(x) x ≥ 0
绝对值 abs(x) 全实数
取整 floor(x) 全实数

完整支持函数列表见 math.js 文档。黑板底层使用 math.js 引擎计算表达式。

函数绘图-续

函数绘图（续）——高级函数功能

本章是函数绘图的延续，介绍函数曲线的操作技巧和高级功能。所有功能需要坐标系。

函数曲线的操作

选中函数曲线

  1. 切换到选择模式（光标图标）
  2. 点击函数曲线上的任意位置
  3. 曲线高亮显示（红色）

修改函数曲线

  1. 双击函数曲线
  2. 在弹出的编辑器中修改表达式或参数
  3. 点击确定，曲线更新

删除函数曲线

选中曲线后按 Delete 键。

修改曲线颜色/粗细

  1. 选中曲线
  2. 调整颜色选择器或线条样式
  3. 曲线即时更新

调整定义域

拖动定义域端点

  1. 函数曲线上有两个控制点（定义域起止标记）
  2. 选中并拖动这些点来改变 x 的范围
  3. 曲线实时裁剪到新范围

函数曲线上的点 [构造]

作用

在函数曲线上创建可滑动的约束点。

操作步骤

  1. 点击左侧菜单 点图标
  2. 将鼠标移到函数曲线上（自动吸附高亮）
  3. 点击创建约束点
  4. 拖动点时，点沿曲线移动，自动更新对应的 y 值

绘制函数曲线的切线 [构造]

作用

在函数的指定点处绘制切线。

操作步骤

  1. 在函数曲线上创建一个约束点
  2. 选中该点
  3. 点击左侧菜单 更多 → 代数图形 → 切线
  4. 切线自动计算并绘制

多函数叠加

同一坐标系下绘制多条曲线

  1. 建立坐标系
  2. 依次使用「任意函数」创建多条曲线：
    • y = sin(x)
    • y = cos(x)
    • y = sin(x) + cos(x)
  3. 所有曲线共享同一坐标系，便于比较

函数与几何图形结合

求函数与直线的交点

  1. 在函数曲线上方画一条直线（或在函数曲线附近创建一条构造线）
  2. 选中直线和函数曲线
  3. 点击左侧菜单 更多 → 构造交点

函数曲线与圆锥曲线类似，支持所有交点计算。

视频处理

视频处理——录制与播放

本章介绍黑板的视频录制和播放功能。录制功能可将画布操作过程录制成 WebM 视频文件，播放功能支持在黑板内直接播放视频。

录制视频

作用

将黑板画布上的操作过程录制成视频文件（WebM 格式），适合录制教学讲解、解题过程等。

操作步骤

  1. 点击右侧菜单 视频 → 录制视频
  2. 在弹出的录制面板中设置参数：
    • 帧率：10 / 15 / 24 / 30 fps（帧率越高画面越流畅，文件越大）
    • 录制音频：开启/关闭麦克风录音
    • 音频来源：麦克风（录制说话声）/ 系统音频（录制电脑内部声音）
  3. 点击 开始录制 按钮
  4. 录制过程中：
    • 画布右上角显示红色录制指示器（闪烁红点 + 计时器）
    • 可关闭录制面板，录制在后台继续
    • 可随时打开面板 暂停 / 继续 / 停止
  5. 点击 停止录制 按钮
  6. 弹出保存对话框，选择保存位置和文件名

录制范围

只录制画布当前视口内的可见区域。超出屏幕范围的画布内容不会被录制。

输出格式

  • 格式：WebM（VP9 编码）
  • 默认文件名：课程录制_YYYY-MM-DD HH-mm-ss.webm

播放视频

作用

在黑板内播放视频文件，支持 WebM / MP4 / MOV 格式，可拖动位置、调整大小。

打开视频的方式

方式一：通过菜单打开

  1. 点击右侧菜单 视频 → 播放视频
  2. 在弹出的视频播放器中点击 选择视频文件
  3. 选择本地视频文件

方式二：直接打开视频文件

  1. 点击左侧菜单 文件夹 → 打开本地文件（或打开百度网盘文件）
  2. 选择 .webm / .mp4 / .mov 文件
  3. 视频自动在播放器中打开

方式三：在最近文件列表中点击 如果之前打开过 .webm 文件，可在左侧文件夹菜单的最近文件列表中直接点击打开。

播放器操作

  • 播放/暂停/进度条：标准视频控件
  • 全屏：点击标题栏全屏按钮或双击视频画面
  • 拖动：按住标题栏拖动播放器位置
  • 调整大小：拖动播放器右下角调整窗口大小
  • 关闭：点击右上角关闭按钮

支持的格式

格式 支持情况
WebM 完全支持（推荐）
MP4 仅 H.264 (AVC) 编码
MOV 仅 H.264 (AVC) 编码

非标准编码的 MP4/MOV 文件无法在黑板内播放，建议使用系统播放器打开。

录制注意事项

录制前准备

  • 确保画布已打开（新建黑板或打开文件）
  • 如需录制音频，确保麦克风权限已授权
  • 系统音频录制需要浏览器/系统支持（Tauri 桌面版支持更完善）

录制过程中

  • 可以在黑板中正常操作（绘图、翻页、切换工具等），所有操作都会被记录
  • 翻页操作也会被录制（切换页面的过程会记录在视频中）
  • 录制的视频不含录制面板本身和顶部指示器

性能建议

  • 帧率建议 15 fps（教学录制足够清晰流畅）
  • 高帧率（24/30 fps）适合录制动画或快速操作
  • 录制时关闭不必要的后台程序以保证流畅度

录制指示器

录制开始后，画布右上角会出现一个半透明的录制指示器：

  • 红点闪烁 + "录制中" + 计时器（如 03:25）
  • 暂停时红点停止闪烁，显示"已暂停"
  • 点击指示器可快速打开录制面板

指示器本身不会被录制到视频中。

视频文件管理

录制产生的 .webm 文件：

  • 可随后在黑板中打开播放（通过打开本地文件）
  • 可作为教学资源上传到百度网盘
  • 可导入到其他页面作为注释（通过打开本地文件方式）
  • 可在文件管理器中直接拖入黑板播放

视频转换

如需将录制视频转换为其他格式，可使用第三方工具（如 FFmpeg）。黑板内置了简单的视频格式检测，播放时自动选择最佳解码方式。
