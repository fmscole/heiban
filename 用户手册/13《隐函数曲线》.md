## 隐函数曲线

### 作用
绘制形如 f(x,y)=0 的任意隐函数曲线。比显函数 y=f(x) 更强大，能表达无法写成 y=f(x) 形式的曲线。

### 前置条件
- 必须先建立坐标系（见第02章）

### 操作步骤
1. 点击左侧菜单 **更多 → 代数图形 → 隐函数曲线**
2. 在对话框中输入表达式（方程的一侧，系统默认 =0），如：
   - `x^2 + y^2 - 1` → 单位圆
   - `x^2/4 + y^2/9 - 1` → 椭圆
   - `y - x^2` → 抛物线（等号表达式自动转换）
   - `x^3 + y^3 - 3*x*y` → 笛卡尔叶形线
3. 也可点击快捷示例按钮快速选择
4. 点击 **创建** 按钮
5. 曲线在画布上绘制（复杂曲线可能需要几秒计算）

### 支持的运算符和函数
| 类别 | 支持内容 |
|------|----------|
| 算术 | +, -, *, /, ^ |
| 三角函数 | sin, cos, tan, asin, acos, atan |
| 双曲函数 | sinh, cosh, tanh |
| 指数对数 | exp, log, log2, log10, sqrt |
| 绝对值 | abs |
| 常量 | pi, e |

## 经典曲线示例

| 曲线名称 | 表达式 |
|----------|--------|
| 单位圆 | `x^2 + y^2 - 1` |
| 椭圆 | `x^2/4 + y^2/9 - 1` |
| 双曲线 | `x^2 - y^2 - 1` |
| 抛物线 | `y - x^2` |
| 笛卡尔叶形线 | `x^3 + y^3 - 3*x*y` |
| 三叶玫瑰线 | `(x^2 + y^2)^2 - 4*x*(x^2 - 3*y^2)` |
| 心形线 | `(x^2 + y^2 - 1)^3 - x^2*y^3` |
| 正弦曲线 | `sin(x) - y` |
| 余弦曲线 | `cos(x) - y` |
| 双纽线 | `(x^2 + y^2)^2 - (x^2 - y^2)` |
| 星形线 | `x^(2/3) + y^(2/3) - 1` |

## 使用技巧

### 等号表达式
输入 `y = x^2` 会自动转换为 `y - x^2`，等价于 `y - x^2 = 0`。

### 计算精度
复杂曲线或表达式变化剧烈的区域可能需要更密集的网格计算。如果曲线有断点或缺失：
- 尝试调整坐标系的显示范围
- 缩小 xmin/xmax/ymin/ymax 范围提高精度

### 与显函数的区别
- **显函数 y=f(x)**：通过「任意函数」工具绘制，速度快，但每个 x 只能对应一个 y
- **隐函数 f(x,y)=0**：通过本工具绘制，能表达闭合曲线和多值函数，但计算较慢
