椭圆有两种创建方式：**画椭圆**（几何方式，鼠标放置控制点）和**圆锥曲线椭圆**（代数方式，输入参数方程）。两种方式产生的椭圆性质不同。

## 画椭圆 [画]

### 作用
通过鼠标放置控制点来画椭圆。适合快速、直观的绘制。

### 操作步骤
1. 点击左侧菜单 **更多 → 几何图形 → 画椭圆**
2. 在画布上点击第一个点（椭圆中心或长轴一端）
3. 点击第二个点（确定长轴方向和长度）
4. 拖动鼠标调整短轴长度
5. 点击确认，椭圆完成

> 画出的椭圆是自由图形，不与坐标系关联。

## 圆锥曲线椭圆 [参数]

### 作用
通过精确的数学参数创建标准椭圆，需要坐标系。

### 前置条件
- 必须先建立坐标系（见第02章）

### 操作步骤
1. 点击左侧菜单 **更多 → 代数图形 → 圆锥曲线椭圆**
2. 在弹出的参数面板中设置：

| 参数 | 说明 | 示例值 |
|------|------|--------|
| a | 半长轴长度 | 4 |
| b | 半短轴长度 | 2 |
| 中心点 x | 椭圆中心x坐标 | 0 |
| 中心点 y | 椭圆中心y坐标 | 0 |
| 旋转角 | 椭圆倾斜角度（度） | 30 |

3. 点击 **创建** 按钮
4. 椭圆按参数生成，从属于当前坐标系

### 参数化椭圆的优势
- 精确的数学定义
- 可设置旋转角度
- 可拖动中心点改变位置
- 坐标变化时椭圆跟随缩放

## 椭圆上的点 [构造]

### 作用
在椭圆周上创建可滑动的约束点。

### 操作步骤
1. 先创建一个椭圆（画椭圆或圆锥曲线椭圆均可）
2. 点击左侧菜单 **点图标**
3. 将鼠标移到椭圆周上（自动吸附高亮）
4. 点击放置点 → 创建"椭圆上的点"
5. 拖动此点时，始终保持在椭圆周上

## 直线与椭圆交点 [构造]

### 作用
求直线与椭圆的交点（0-2个）。

### 操作步骤
1. 选中一条直线
2. 按住 Shift，选中一个椭圆
3. 在右侧菜单点击 **构造 → 直线与椭圆交点**
4. 系统自动计算并创建交点

> 也可使用左侧菜单 **更多 → 构造交点** 批量创建所有交点。

## 椭圆与其他圆锥曲线的交点 [构造]

支持以下圆锥曲线间的交点：
- 圆与椭圆交点
- 椭圆与双曲线交点
- 椭圆与抛物线交点

### 操作步骤
1. 选中两个圆锥曲线图形（Shift+点击）
2. 点击左侧菜单 **更多 → 构造交点**
3. 交点自动计算并创建

## 椭圆参数方程

创建的圆锥曲线椭圆使用标准参数方程：

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$

如需更复杂的椭圆（如倾斜椭圆），可在参数面板中设置旋转角。
