本章介绍双曲线和抛物线的参数化创建方式。与椭圆类似，圆锥曲线双曲线/抛物线通过参数面板精确创建，属于 **[参数]** 模式，需要坐标系。

## 圆锥曲线双曲线 [参数]

### 作用
创建标准双曲线，可显示渐近线。

### 前置条件
- 必须先建立坐标系（见第02章）

### 操作步骤
1. 点击左侧菜单 **更多 → 代数图形 → 圆锥曲线双曲线**
2. 在参数面板设置：

| 参数 | 说明 | 示例值 |
|------|------|--------|
| a | 实半轴长度 | 3 |
| b | 虚半轴长度 | 2 |
| 中心点 x | 双曲线中心x坐标 | 0 |
| 中心点 y | 双曲线中心y坐标 | 0 |
| 开口方向 | 横向(x轴) 或 纵向(y轴) | 横向 |
| 显示渐近线 | 是否显示两条渐近线 | ✓ |

3. 点击 **创建** 按钮

### 双曲线方程
- 横向开口：$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$$
- 纵向开口：$$\frac{y^2}{a^2} - \frac{x^2}{b^2} = 1$$

### 渐近线
勾选"显示渐近线"后，两条渐近线自动绘制：
- $$y = \pm \frac{b}{a}x$$（横向开口）

## 圆锥曲线抛物线 [参数]

### 作用
创建标准抛物线，支持四种开口方向。

### 前置条件
- 必须先建立坐标系

### 操作步骤
1. 点击左侧菜单 **更多 → 代数图形 → 圆锥曲线抛物线**
2. 在参数面板设置：

| 参数 | 说明 | 示例值 |
|------|------|--------|
| p | 焦距（焦点到准线的距离） | 2 |
| 顶点 x | 抛物线顶点x坐标 | 0 |
| 顶点 y | 抛物线顶点y坐标 | 0 |
| 开口方向 | 上/下/左/右 | 上 |

3. 点击 **创建** 按钮

### 抛物线标准方程
- 开口向上：$$y = \frac{x^2}{4p}$$
- 开口向下：$$y = -\frac{x^2}{4p}$$
- 开口向右：$$x = \frac{y^2}{4p}$$
- 开口向左：$$x = -\frac{y^2}{4p}$$

## 双曲线/抛物线上创建点 [构造]

与椭圆类似，可以使用点工具的吸附功能在双曲线或抛物线上创建可滑动的约束点。

### 操作步骤
1. 点击左侧菜单 **点图标**
2. 将鼠标移到双曲线或抛物线上（自动吸附）
3. 点击创建约束点

## 圆锥曲线交点 [构造]

### 支持的曲线间交点
- 直线与双曲线交点
- 直线与抛物线交点
- 圆与双曲线交点
- 圆与抛物线交点
- 椭圆与双曲线交点
- 抛物线与椭圆交点
- 抛物线与双曲线交点

### 操作步骤
1. 选中两个图形（Shift+点击）
2. 点击左侧菜单 **更多 → 构造交点**

## 圆锥曲线圆 [参数]

### 作用
通过参数方程创建精确的圆，是"圆锥曲线椭圆"的特例（a=b）。

### 操作步骤
1. 点击左侧菜单 **更多 → 代数图形 → 圆锥曲线圆**
2. 设置半径和中心点坐标
3. 点击 **创建**

> **与"画圆"的区别**：圆锥曲线圆使用坐标定义，随坐标系缩放；"画圆"是自由图形，不依赖坐标系。

## 切线工具 [构造]

### 作用
过曲线上一点作该曲线的切线。支持任意函数曲线和圆锥曲线。

### 前置条件
- 需要有一个函数曲线（任意函数/二次函数等）或圆锥曲线
- 需要曲线上有一个约束点

### 操作步骤
1. 在曲线上创建一个点（用点工具吸附到曲线上）
2. 选中该点
3. 点击左侧菜单 **更多 → 代数图形 → 切线**
4. 切线自动创建，过该点且与曲线相切

### 操作步骤（替代方式）
1. 点击左侧菜单 **更多 → 代数图形 → 切线** 进入切线模式
2. 点击曲线上的某位置
3. 切线和切点自动创建

> 切线使用曲线在该点的导数计算斜率，因此只对可导函数有效。

## 圆锥曲线对比一览

| 类型 | 标准方程 | 参数数量 | 渐近线 |
|------|----------|----------|--------|
| 椭圆 | x²/a² + y²/b² = 1 | a, b, 中心, 旋转角 | 无 |
| 双曲线 | x²/a² − y²/b² = 1 | a, b, 中心, 方向 | 两条 |
| 抛物线 | y = x²/(4p) | p, 顶点, 方向 | 无 |
| 圆 | x² + y² = r² | r, 中心 | 无 |
