变换操作属于 **[构造]** 模式——需先选中对象，再通过右侧菜单执行。变换结果保留原始对象，与原对象保持**动态关联**（修改原对象或变换参数时结果自动更新）。可对结果再次变换（链式变换），删除变换结果选中后按 Delete 键。

> **通用前提**：所有变换操作都需要先选中至少一个对象。

## 旋转 [构造]

将选中对象绕指定中心点旋转一定角度。

1. 选中要旋转的对象（可多选）
2. 右侧菜单 **运动 → 旋转**，设置角度（度数或弧度）
3. 点击旋转中心点（或选择已有点）
4. 旋转后的图形创建，原始对象保留

## 点对称（中心对称）[构造]

创建关于某中心点对称的图形。

1. 选中要变换的对象
2. 右侧菜单 **运动 → 点对称**
3. 点击对称中心点
4. 对称图形自动创建（拖动中心点，对称图形跟随更新）

</div>
<div>

## 轴对称（翻折）[构造]

创建关于某直线对称的图形。

1. 选中要变换的对象
2. 右侧菜单 **运动 → 轴对称**
3. 点击作为对称轴的直线
4. 对称图形自动创建（移动对称轴，图形跟随翻折）

## 缩放 [构造]

按比例放大或缩小图形。

1. 选中要缩放的对象
2. 右侧菜单 **运动 → 缩放**，设置比例 m/n（实际比例 = m÷n）
3. 点击缩放中心点
4. 缩放图形创建（如 m=2,n=1 放大2倍，m=1,n=2 缩小为1/2）

## 平移 [构造]

将图形按指定向量平移。

1. 选中要平移的对象
2. 右侧菜单 **运动 → 平移**
3. 依次点击平移向量的起点和终点
4. 图形按向量方向和距离平移（修改向量起终点会联动更新）
